# CCEI RGB Pool LED Light
an rgb pool led light controler for CCEI Noria RGBW led pool light

![alt text](https://github.com/krissfr/CCEI_RGB_Pool_LED_Light/blob/main/bigpicture.jpg)

For this projet, you need :
- 1 ccei rgbw led pool light (i use noria 30w RGBW)
- 1 voltage converter 12v ac to 5v dc
- 1 robodyn ac dimmer (i use the 4A version witch is low profile)
- some cables and connectors

for testing i just slide the esp32c6 on the ac dimmer's pins (be carful to put 3.3v on vcc and gnd on gnd.
